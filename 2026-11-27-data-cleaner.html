data_cleaner

How it works

make the fake data → plant errors → auto-fix the safe ones → run every rule (as SQL, in DuckDB) → split passed / held back → score against the planted errors. Every setting is in config/. Each table's rules also list a SQL Server connection (placeholders only), so the same rules can later run against a real database.
